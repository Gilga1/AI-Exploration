# Semantic Layer Shell

A platform-agnostic semantic layer backed by a Neo4j knowledge graph. AI agents select metrics, entities, and dimensions from the graph; SQL is **assembled deterministically** in Python — never generated by an LLM.

**Pilot:** Intelligence Hub — grounded query pipeline with entity resolution, global filters, structured insights, charts, and YAML validation policies.

## Quick start

```bash
cd semantic-layer-shell
cp .env.example .env    # add OPENAI_API_KEY + SNOWFLAKE_* credentials
bash scripts/setup.sh

cd backend && source .venv/bin/activate
uvicorn app.main:app --reload --port 8000
```

Frontend (separate terminal):

```bash
cd semantic-layer-shell/frontend && npm run dev
```

Open http://localhost:5173
